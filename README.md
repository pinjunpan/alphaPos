# alphaPos
簡易的飲料店 POS 系統，計算各品項數量及價錢

<img width="959" alt="main" src="https://github.com/user-attachments/assets/220519ef-5b8f-46c9-8278-061ef466231a" />

## Features
- 選擇各式茶類、冰量及糖度，加入待結帳清單
- 依據各品項價錢及數量，計算總額
- 調整畫面，讓清單列有飲料時，才顯示結帳按鈕
